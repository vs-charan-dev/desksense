OPTION 1: LIVE WEBCAM HUD & VISION PROTOTYPE
--------------------------------------------------------------------------------
Runs real-time camera tracking with on-screen HUD (posture, head pose, FPS, presence).

OPTION 2: FULL DESKTOP APPLICATION & DASHBOARD UI
--------------------------------------------------------------------------------
Runs the complete host controller, background engines, and interactive React UI.

Step 1: Start the Backend & Local API Server (Terminal 1)
---------------------------------------------------------
  & "C:\Users\venka\.venv\Scripts\python.exe" main.py

  (Starts the local host and embedded API server at http://127.0.0.1:8765)
  Optional flags:
    --port 8765     (Custom port, default 8765 matches UI)
    --mock          (Run with synthetic test frames instead of live webcam)
    --widget        (Enable floating status pill widget)

Step 2: Start the Dashboard UI (Terminal 2)
-------------------------------------------

  npm run dev

  Open your browser to:
  http://localhost:5173
